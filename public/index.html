ASSUMPTIONS DRIVE VALUE

看清估值背后的假设。

FCFF / WACC 企业估值，明确区分企业价值与股权价值，查看敏感性。

此处参数是你输入的假设，不是系统的盈利预测。FCFF 通常由税后经营利润、折旧摊销、资本支出和营运资本变动推导；CFO−Capex 不自动等于 FCFF。金融企业需使用适用的估值模型。

LOCAL BY DESIGN

可检查，也可追溯。

查看模型连接、数据范围和本地运行状态。

模型连接

密钥由服务端从 .env 读取，不返回浏览器。修改 .env 后重启服务。默认并发 2，完整研究 8 次角色调用及最多 3 次搜索，限流/服务错误最多重试一次；实际 token 用量随报告保存。

数据与覆盖范围

  • 行情、日线、财务：东方财富 / 腾讯等公开接口，逐项显示抓取状态。
  • A 股：三大报表、TTM、5 年年度历史、同业、股东、质押、分红及公告。
  • 港美股：多周期行情、三大报表、财务指标和 5 年年度历史；财年和币种单独处理。
  • 宏观：中国 CPI / GDP；境外宏观和利率汇率需补充核验。
  • ESG 授权评级、市占率、治理和诉讼不保证全覆盖，可在研究资料中补充。

运行与隐私

默认服务仅绑定 127.0.0.1。报告、自选、持仓、缓存位于项目 data 目录；模型分析会把当前股票证据及你补充的资料发送到所选模型供应商。持仓数量和成本不进入专业研究请求。

双击“启动股研助手.cmd”运行；双击“停止股研助手.cmd”停止。Markdown / JSON 可导出，研究报告可打印为 PDF。

系统用于研究辅助，不连接交易账户、不自动下单。已提供的历史财报可能包含后续重述，不可直接用于基本面历史回测。
