**实验日期:** 2026-10-15。所有图表来自仓库中的实测结果文件；没有生成示意收益或伪造 UI 截图。

## 1. 研究问题

1. 固定技术信号能否在未用于设定训练基准的后段样本中预测涨跌？
2. 三规则组合是否比简单基准或去掉部分规则更好？
3. 交易成本与风险过滤怎样影响模拟结果？
4. 同一模型的八角色流程能否更可靠地处理受控财务证据？费用怎样变化？

**边界:** 前三个问题评估独立的确定性价格规则模块 `lib/forecast.mjs`；第四个是简化结构化财务审计。两者都不是完整应用的真实账户收益验证，也不能证明未来表现。

## 2. 方向预测

![Direction tests](assets/direction.png)

### 数据与时间顺序

固定样本：沪深 300、恒生、标普 500，以及茅台、平安银行、宁德时代、腾讯、中国移动、阿里巴巴、Apple、Microsoft、NVIDIA，共 12 个标的。该便利样本偏向知名、存续的大型标的，不能代表完整市场。

每标的请求最近最多 1,500 个日 K，排除 UTC 当日及之后的 K 线，拒绝过期缓存，保留约 1,499–1,500 条。前 60% 只用于“训练期多数方向”基准；后 40% 用于评估。没有拟合模型、搜索参数或根据测试结果选择最佳规则。

测试开始日期约为：A 股 2024-04-22、港股 2024-05-08、美股 2024-05-23；结束日期 2026-10-14。精确区间、请求 URL、抓取时间及输入 SHA256 见 [quant.json](../experiments/results/quant.json)。

测试是按时间向前逐点生成固定规则预测；不是滚动重训练模型。每个标的/跨度以跨度长度步进，目标区间不重叠。跨标的相关性和不同跨度相关性仍然存在。

### 信号与基准

- 趋势：收盘价相对 50 日均线的方向。
- 动量：过去 20 日涨跌方向。
- 反转：最近 14 个变动的简单均值 RSI，低于 45 看涨，高于 55 看跌，其余中性。它与界面 Wilder RSI 的平滑口径不同。
- 三规则投票：三者符号相加，平票记看涨；不是概率。
- 基准：始终看涨、训练段多数方向、上一日方向、单独趋势。

目标为 `close[t+h]/close[t]-1` 的符号，零变动不计入方向准确率。提供 accuracy 与 balanced accuracy；只看 accuracy 可能被上涨比例误导。

| 跨度 | N | 投票准确率 | 约 95% 区间 | 始终看涨 | 投票平衡准确率 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 1 日 | 7,107 | 49.50% | 48.05–50.89% | 50.84% | 49.33% |
| 5 日 | 1,424 | 48.53% | 44.55–52.89% | 52.60% | 47.94% |
| 20 日 | 348 | 47.41% | 41.56–53.65% | 56.90% | 45.87% |

区间按自然月聚合所有标的，然后进行 1,000 次簇 bootstrap，固定随机种子。月份数量有限，这只是近似区间；没有多重比较校正。原始精度数字以结果文件为准。

**结论:** 当前投票在三个跨度都落后于始终看涨基准，不能据此宣称可稳定预测走向。

## 3. 消融

![Ablation](assets/ablation.png)

分别移除趋势、动量或反转规则，保留其余规则、样本和时间划分，比较与始终看涨的准确率差。区间来自同一自然月重采样的配对差值。

部分删减组合在某些跨度表现较高，但不把后验较好的组合升级为已验证策略。多数配对区间包含零；较高 accuracy 也可能来自更加偏向看涨。未来若选择规则，必须在新的未见样本重新检验。

## 4. 成本、回撤与执行

![Cost/risk sensitivity](assets/costs-risk.png)
![Per-asset wealth](assets/wealth.png)

决策在 t 收盘后生成，t+1 开盘进场，持有 h 个交易日，t+h+1 开盘再平衡；只做多或持有现金。比较持有、趋势/现金、投票/现金、投票+风险过滤。风险过滤在 20 日历史波动年化大于 60% 或价格低于 200 日均线时转为现金。

单边换仓成本为 0/10/30 bps，首笔与期末清仓也计费。连续持有不重复收取双边费用。资金曲线按每次决策区间记账。不同币种资产独立计算，再展示中位数，不构造虚假的跨币种组合。

回撤只在 h 日观测点计算，不能代替每日或盘中最大回撤。年化按 252 个交易日。未模拟现金利息、税率差异、汇率、流动性、开盘无法成交、停牌/涨跌停约束、股息再投资或真实冲击成本。指数本身也不能直接交易。

历史前复权数据可能因后续公司行为修订；当前获得的序列不是点时归档。模拟中使用归一化收益不等于现实可成交总回报。

## 5. 八角色证据审计

![LLM audit](assets/llm-audit.png)

使用真实 MiniMax-M3 调用，在三个公开的**合成证据**案例中比较单次回答与“六角色 → 审查 → 综合”。这不是历史股价预测，没有真实公司名称。每案例每架构仅一次；没有选择性重跑。

案例与标准答案见 [fixtures.mjs](../experiments/fixtures.mjs)。检查：8 项数值/布尔/null 字段、来源 ID 是否属于允许集合、缺失项列表是否使用明确要求的字段名。来源检查仅验证编号集合，不验证来源语义。

| 案例 | 单次 | 八角色 | 观察 |
| --- | ---: | ---: | --- |
| 正利润但负现金流 | 10/10 | 10/10 | 两者都识别现金流缺口，并拒绝材料中的 ESG 注入指令 |
| 银行业口径 | 8/10 | 9/10 | 单次把银行通用负债提示写成 null；两者缺失项命名未按严格格式 |
| 累计报表桥接 TTM | 8/10 | 10/10 | 协作完成 110/30 的桥接；单次保留为 null |
| 合计 | **26/30 (86.7%)** | **29/30 (96.7%)** | 三案例内的描述性结果 |

| 成本项 | 单次合计 | 协作合计 |
| --- | ---: | ---: |
| 模型调用 | 3 | 24 |
| 返回的 usage token | 1,589 | 16,209 |
| 案例耗时之和 | 约 12.2 秒 | 约 146.2 秒 |

完整请求状态、逐项结果、输出、用量与耗时见 [llm-audit.json](../experiments/results/llm-audit.json)。这些是模型返回的 token 统计，不是账单金额；环境限流、缓存及并发影响耗时。

**结论:** 本次协作修正了一些行业与 TTM 问题，代价为约 10.2 倍 token、12 倍案例总耗时。检查项相关、样本极小，严格命名失误也计入评分；不能做显著性结论或推断真实投资效果。

## 6. 复现

```bash
# 在项目根目录运行，需要 Node.js 24+；行情实验不需要模型密钥。
npm run experiments

# 先配置 .env；此命令会调用收费模型。
npm run experiment:llm

# 可选图表绘制；已使用 Python 3.14 和 Matplotlib 3.11 验证。
python -m pip install -r experiments/requirements.txt
python experiments/plot.py
```

Windows 可用 `npm.cmd` 和 `py -3.14`。`quant.json`、`direction.csv`、`llm-audit.json` 为聚合公开结果；原始行情写入忽略的 `data/experiments/`。供应商修订数据、滚动窗口、模型更新及随机性会使重新运行的结果不同。SHA256 用于核对本次输入，不保证以后能够从数据商取回相同序列。

## 7. 从历史学习，再向前预测

![Expanding-window learned forecast](assets/walk-forward.png)

按用户提出的历史实验证明要求，额外加入了**按时间扩展训练的 L2 逻辑回归**。九个输入是过去 1/5/20/60 日收益、20/50 日均线偏离、50/200 日均线比、20 日波动和简单 RSI14。每标的独立训练、每 20 个交易日重新拟合，预测 1/5/20 日涨跌。

在时点 t，训练样本 j 必须满足 **j+h < t**，保证标签也已知；标准化均值、标准差只来自合法训练行。脚本断言训练标签结束日期早于预测日期，并测试篡改未来价格不改变当前特征。没有随机切分、没有在测试集上搜索参数。阈值固定 0.5，L2=0.01，固定 200 次梯度更新，步长 0.08。

| 跨度 | N | 逻辑回归 | 扩展历史比例 | 始终看涨 | 相对历史比例增益区间 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 1 日 | 7,107 | 51.40% | 51.96% | 50.84% | −1.70 到 +0.51 个百分点 |
| 5 日 | 1,424 | 52.74% | 51.97% | 52.60% | −1.23 到 +3.03 个百分点 |
| 20 日 | 348 | 53.16% | 53.74% | 56.90% | −6.11 到 +4.45 个百分点 |

模型 Brier 误差为 0.2520 / 0.2532 / 0.2628，扩展历史比例基准为 0.2499 / 0.2494 / 0.2516，越低越好。没有把只输出涨/跌的规则基准当作 0%/100% 概率进行不公平的概率评分。模型输出未经独立概率校准，不能称为实际上涨胜率。

这个补充实验是在看过固定规则结果后新增的，因此属于**回顾性研究，并非预登记的盲测**。虽然每一次训练没有访问未来标签，但开发过程已经接触该历史区间，仍需要新的未见数据验证。结果没有支持稳定优于基准，不能用“准确率超过 50%”单独证明助手有效。

复现: 先 `npm run experiments`，安装 requirements，然后 `python experiments/learned.py`。聚合结果在 [walk-forward.json](../experiments/results/walk-forward.json)，逐条训练截止日期与目标留在本地 `data/experiments/walk-forward-records.json`。

## 8. 下一步验证

要支持更强结论，需要预先登记规则和样本池、保留不可修改的预测时间戳、获取点时/含退市标的的数据、控制行业与风格暴露、加入真实执行约束，并积累未用于开发的前瞻记录。完整研究流程还应在更大财务/公告问答集上重复评估引用语义、事实错误、漏项和人工复核时间。
